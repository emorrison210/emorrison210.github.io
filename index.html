04

In-Game Inventory System

CMPT 307 · Databases · Individual Project

A database-driven inventory management system inspired by games like Elden Ring. Players can add, remove, and organize items such as weapons, potions, and armor. Uses SQL commands for CRUD operations, GROUP BY and COUNT for summaries, and subqueries to find rare items or the largest inventories.

Reflection

This project helped me understand how databases work in a practical context - connecting a Java application to MariaDB, organizing data into normalized tables, and using foreign keys to maintain relationships. Turning a game concept into a working relational database pushed my creativity, and writing complex SQL queries strengthened my critical thinking. Presenting the design and results improved my ability to communicate technical decisions clearly.

SQL Database Design Java
05

CityRoute Visualizer

CMPT 306 · Algorithms · Individual Project

Python project modeling U.S. cities as a weighted graph to find shortest paths using Dijkstra's and A* algorithms. Parses CSV data, builds the graph programmatically, and renders results on an interactive map visualization.

Reflection

Implementing Dijkstra's and A* from scratch gave me a much stronger grasp of graph theory and algorithm efficiency than any textbook could. Translating abstract data structures into a visual, interactive map made the results tangible and helped me understand how data visualization can turn raw output into something immediately meaningful. This project sharpened both my problem-solving skills and my ability to present technical work clearly.

Python Dijkstra's / A* Data Visualization
